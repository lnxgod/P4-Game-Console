P4 Console OS - M5Stack Tab5

Copy this generated directory to a FAT32 microSD card while the Tab5 is powered off.
Eject the card cleanly before inserting it. Keep GAMES, P4 and UPDATE directories.
Never remove microSD while the console is running or saving.
This development target uses touch and microSD; USB Drive and C6 radio are not enabled.
Hardware acceptance is pending. Firmware must not be installed before a complete
factory backup and exact device/revision checks. WAD data stays local.
