# Orble

Orble is an original P4 Game API puzzle cartridge: aim a bright orb through
three compact peg boards, clear every target, and catch the orb in the moving
collector to preserve your ball supply. Left/right set the aim, A launches,
and B restarts the campaign.

This is a clean-room implementation. The public GameChangers page was used
only to identify the game name and broad genre; no source code, art, audio,
level data, or other protected game assets were imported. Its graphics are
original code-rendered shapes plus the Console API's shared original ImageGen
feedback atlas.

The native `ORBLE.P4G` is built from `game.json`; copy it into `GAMES/` on the
P4 GAMES USB volume to install without reflashing the Console OS.
