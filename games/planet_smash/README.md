# Planet Smash

Planet Smash is an original P4 Game API orbital-defense cartridge. Rotate the
planetary cannon with left/right, press A to fire, and protect the planet's
three shield segments over three increasingly busy waves. B restarts a run.

No public Planet Smash implementation was found in the GameChangers community
arcade during this work, so this cartridge is an original game rather than a
code or asset port. Its visual language is original code-rendered geometry
plus the Console API's shared original ImageGen feedback atlas. An exact
GameChangers URL can be used to review its intended mechanics separately.

The native `PLANET_SMASH.P4G` is built from `game.json`; copy it into `GAMES/`
on the P4 GAMES USB volume to install without reflashing the Console OS.
