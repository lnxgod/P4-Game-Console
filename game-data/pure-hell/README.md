# Pure Hell v0.5

[Monorepo](../../README.md) · [Arena game](../../docs/games/arena/README.md)

Pure Hell is a two-map content pack for the arena game, not Console OS or a
standalone cartridge. The game mode and this preserved map pack have separate
source, data and verification records.

[Download PUREHELL.WAD](v0.5/PUREHELL.WAD) — 875,026 bytes, SHA-256
`b0e8ab211fe263bdf263b219cd0f3584cac0071ec1cf3ce73defa843f00a3663`.

The owner requested that these original reconstructed maps be included in this
repository. MAP01 is the shotgun arena; MAP02 is the rocket arena. Each has
eight deathmatch starts. These are newly reconstructed maps based on Will’s
rough 2012 sketch, not a recovered historical WAD.

The pack is preserved unchanged, including its [original README](v0.5/README.txt),
[build manifest](v0.5/build-manifest.json), standalone MIDI and credits.
“Beasts of Horizon” by Josephus “DH4050” Astartes comes from Freedoom 0.13.0;
retain [the BSD license](v0.5/Freedoom-0.13.0-COPYING.txt),
[music credits](v0.5/Freedoom-0.13.0-CREDITS-MUSIC.txt) and
[project credits](v0.5/Freedoom-0.13.0-CREDITS.txt) when sharing the pack.

The Game Changers AI mode overrides ordinary progression to loop MAP01 ↔ MAP02,
including secret exits. The preserved original README describes behavior in
other engines. The mode uses Freedoom Phase 2 for base graphics and sounds.

See [setup, verified downloads and multiplayer controls](../../docs/GAME_CHANGERS_AI_DOOM.md).
