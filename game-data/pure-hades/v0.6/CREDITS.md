# Pure Hades credits

- Concept and rough 2012 Pure Hell sketch: Will Hatzer.
- New reconstruction, Pure Hades variants, build tools and original documentation: Codex for Will Hatzer, 2026. The historical Pure Hell WAD was not recovered.
- Base game data and font artwork: Freedoom Phase 2 0.13.0 contributors, BSD 3-Clause. [Official release](https://github.com/freedoom/freedoom/releases/tag/v0.13.0). Matching license and contributor lists are included under `licenses/`.
- Validation engine: Chocolate Doom 3.1.1, GPL-2.0-or-later. No engine binary is distributed in this package. Gameplay tests use the unmodified engine; music/preview capture uses disclosed logging and capture hooks without changes to gameplay or music rules.
