# Pure Hades for Game Changers AI

Pure Hades v0.6 replaces Pure Hell in the Tab5 arena bundle. The five maps are
Shotguns, Rockets, Plasma, Pure Chaos, and Double-Barrel Finale.

The authoritative map project is [lnxgod/pure-hades](https://github.com/lnxgod/pure-hades).
This directory vendors its exact [v0.6 commit](https://github.com/lnxgod/pure-hades/tree/142c6ff56ff8fb9eee40e6b2ea7875a0424337e8),
including all source, music, artwork, license notices and upstream validation.
The upstream files under `v0.6/` remain byte-for-byte unchanged; the complete
hash inventory is [third_party/pure-hades.json](../../third_party/pure-hades.json).
Make map changes in the source repository, then update this pinned import.

`PUREHADES.WAD` is 2,313,392 bytes, SHA-256
`ab027fbeebe20787214a3bc1239bba73271030dc284cd108c20ae8bc73752fc8`.
See the [upstream README](v0.6/README.md), [license](v0.6/LICENSE) and
[credits](v0.6/CREDITS.md). The repository WAD exception applies only to this
original, licensed pack; Freedoom and DWANGO stay local, verified inputs.

For the complete SD bundle, USB provisioning and multiplayer test instructions,
see [the arena guide](../../docs/GAME_CHANGERS_AI_DOOM.md).
